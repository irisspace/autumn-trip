上傳 GitHub Pages
  1. 到 github.com 建一個新的 repository（例如 autumn-trip），Public。
  2. 在 repository 頁面按「uploading an existing file」，把這個資料夾裡「全部的檔案和 images 資料夾」拖進去（不要拖外層資料夾本身），按 Commit changes。
  3. Settings → Pages → Source 選「Deploy from a branch」，Branch 選 main、資料夾 / (root)，按 Save。
  4. 等 1–2 分鐘，網址會是 https://你的帳號.github.io/autumn-trip/

之後要修改：在 GitHub 上點檔案 → 鉛筆圖示編輯 → Commit，約一分鐘後網站更新。
